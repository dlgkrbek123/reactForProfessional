useState
- 내부적으로 useReducer를 포함하고 있음

function useState() {
  const [state, dispatch] = useReducer(
    (state, newValue) => newValue,
    initialValue
  )

  return [state, dispatch]
}

useReducer
- 복잡한 상태관리에 적합

- 상태업데이트 로직이 컴포넌트에서 분리되어 SRP를 따르기 쉽다.
  - 리듀서만 테스팅 가능
- 상태와 변경이 useReducer를 통해서만 명시적으로 이뤄짐
- 이벤트 소스 모델로서 기능할 수 있음

immer로 복잡한 상태관리를 간단히 처리
- 중첩된 상태를 draft를 수정하는 식으로 처리
- 리듀서를 직관적으로 작성하게 해줌
- Object.assign이나 전개 연산자를 복잡하게 안써도 됨
- useState나 useReducer와 붙혀서 쓰면 좋을지도
