---------------------------------------------------------------------------------------------

지연 로딩 (lazy loading)
- 페이지 로딩시가 아니라 hover, click같은 액션이 일어날떄 나중에 로딩

---------------------------------------------------------------------------------------------

React.lazy
- 컴포넌트 지연 로딩
- 렌더링되기 전에는 모듈을 로드하지도 호출하지도 않음

// 동적으로 로딩
const Sidebar = lazy(() => import("./Sidebar"))

<Suspense fallback={<div>닫혀있는 사이드바</div>}>
  {show && <SideBar />}
</Suspense>

---------------------------------------------------------------------------------------------

Suspense
- Promise가 resolve 되기전에 fallback을 표시
- 모든 비동기 자식의 Promise가 resolve되기전까지 fallback이 렌더링됨
