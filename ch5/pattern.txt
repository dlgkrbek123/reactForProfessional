고차함수 (High Order Function)
- 하나 이상의 함수를 인수로 취하여 함수를 결과로 반환하는 함수

고차컴포넌트
- 컴포넌트를 인수로 받아 합성된 새로운 컴포넌트를 반환하는 함수
- 반복을 줄이기 위함

const withAsync = (Component) => (props) => {
  if(props.loading) return "로딩 중..."

  if(props.error) return props.error.message

  return <Component {...props} />
}

hooks에 의해 많이 대체됨...

render props
- 컴포넌트 내부에 그릴 내용을 props로 전달받기
- 렌더링 작업에 대한 제어를 부모에게 넘겨 제어를 역전

children도 props이므로 이를 활용해서 render props를 적용

이것도 hooks로 많이 대체...

---------------------------------------------------------------------------------------------

Controlled Component
- 내부에 자체상태를 유지하지 않는 컴포넌트
- 상태가 부모 컴포넌트에 의해 props로 전달되어 결정 (부모 컴포넌트가 source of truth)
- 부모가 전달한 콜백을 호출하여 상태를 관리하게 시킴
- 상태를 관리하고 컴포넌트의 값을 업데이트하는 책임이 부모 컴포넌트에 위임

Controlled Props
- Controlled Component를 확장한 개념
- 컴포넌트가 state, update하는 함수 2가지를 props로 전달받음
- 부모가 값을 전달하는 경우 해당 값을 따르고 아닌 경우 내부 state로 관리하게 하여 2가지 케이스에 대해 대응
