JSX
- html과 유사한 문법을 제공하여 
- X는 확장구문(extension)을 의미한다. => javascript XML
- js코드에서 HTML과 유사한 코드를 작성하게 해주는 구문확장자 / 확장구문

---------------------------------------------------------------------------------------------

- JSX로 작성한 확장구문은 컴파일링되어 JS코드로 변환됨
- 원래는 아래와 같은 코드를 써야 하는데 JSX로 작성하고 변환함으로써 가독성과 유지보수성을 보장
- 근데 어떻게보면 상태등의 JS코드 밑에 html 비슷한 코드가 있어서 관심사가 혼합되었다고 까임

React.createElement(
  'section',
  { id: list },
  React.createElement('h1', {}, "내가 만든 목록!"),
  ...남은 children들
)
// 최신버전은 _JSXS()

babel이 트랜스파일링 해줘서 JSX가 위와같은 함수호출로 변경
- 한 언어로 작성한 소스코드를 다른 언어의 소스코드로 변환

function pragma(tag, props, ...children)
