리액트 서버 컴포넌트
- 서버에서만 실행되는 컴포넌트
- 클라이언트 번들에 포함되지 않음

- MPA와 SPA의 장점을 결합
- APP의 성능, UX를 개선하기 위해 설계됨

서버에서 실행되므로 보안이나 성능 측정등을 쉽게 가능하게 하며
비동기로 동작할 수 있다.

---------------------------------------------------------------------------------------------

1. RSC렌더러: 서버 컴포넌트를 실행하여 ReactElement 트리로 변경하는 프로세스
2. 서버렌더러: ReactElement를 HTML 스트림으로 바꾸는 프로세스

엘리먼트 트리가 문자열로 직렬화됨
클라이언트는 전송 받고 이걸 기반으로 렌더링

서버 컴포넌트가 못되는 컴포넌트 (직렬화 불가능)
- 부작용이 있는 hooks가 (useState, useEffect)
- 이벤트 핸들러를 부착
- 전역상태 접근 (클라별로 상이하므로)
